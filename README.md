# Monitor IERF – CATU

PWA de diagnóstico del **Índice de Exposición al Riesgo Fiscal** por las 5 etapas del ciclo de obra pública (LOPSRM / RLOPSRM).

## Qué incluye

- Tokens navy + oro de la suite CATU
- Ciclo legal y 3 reactivos en la misma etapa (`#ciclo-informativo`)
- El IERF no se interpreta hasta 8 respuestas
- Dictamen: anillo, barras por etapa, 3 hallazgos
- PWA (`manifest.json` + `sw.js`)
- Correo: centro.catu@gmail.com
